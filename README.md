# Renato Cruz Portfolio

A modern, responsive one-page portfolio website showcasing web development skills, projects, and professional experience. Built with a clean, Apple-inspired design aesthetic.

## 🚀 Features

- **Responsive Design**: Optimized for desktop, tablet, and mobile devices
- **Apple-like UI**: Clean, minimalist design with smooth animations
- **Modern Stack**: Built with HTML5, CSS3, JavaScript, and Tailwind CSS
- **Performance Optimized**: Fast loading with minimal dependencies
- **SEO Ready**: Comprehensive meta tags and structured data
- **Accessibility**: WCAG compliant with proper semantic HTML

## 📁 Project Structure

```
renato-portfolio/
├── index.html          # Main HTML file
├── assets/
│   ├── styles.css     # Custom CSS styles
│   ├── script.js      # JavaScript functionality
│   ├── favicon.svg    # Site favicon
│   ├── profile.jpg    # Profile picture (replace with actual photo)
│   └── placeholder-*.jpg # Project images (replace with actual screenshots)
└── README.md          # This file
```

## 🛠️ Technologies Used

- **HTML5**: Semantic markup and modern web standards
- **CSS3**: Custom properties, flexbox, and grid layouts
- **Tailwind CSS**: Utility-first CSS framework via CDN
- **JavaScript**: Vanilla JS for interactions and animations
- **Inter Font**: Modern typography from Google Fonts

## 🎨 Design Features

- **Dark Theme**: Professional dark color scheme with ink palette
- **Smooth Animations**: Intersection Observer for reveal effects
- **Glass Morphism**: Subtle backdrop blur effects
- **Gradient Accents**: Soft gradients for visual interest
- **Typography**: Clean, readable Inter font family

## 📱 Responsive Breakpoints

- **Mobile**: < 768px (single column layout)
- **Tablet**: 768px - 1024px (adjusted grid layouts)
- **Desktop**: > 1024px (full multi-column layouts)

## 🚀 Getting Started

### Local Development

1. **Clone or download** the project files
2. **Open** `index.html` in your web browser
3. **Customize** content, images, and links as needed

### Customization

#### Replace Images
- `assets/profile.jpg`: Your professional headshot (circular crop recommended)
- `assets/placeholder-1.jpg`: E-commerce project screenshot
- `assets/placeholder-2.jpg`: Analytics dashboard screenshot  
- `assets/placeholder-3.jpg`: Portfolio engine screenshot

#### Update Content
- **Personal Information**: Name, title, location in About section
- **Skills**: Add/remove technologies in Skills section
- **Projects**: Update project titles, descriptions, and links
- **Contact**: Update email, LinkedIn, and GitHub URLs

#### Styling
- **Colors**: Modify the `ink` color palette in Tailwind config
- **Fonts**: Change font family in the Google Fonts link
- **Spacing**: Adjust padding/margins using Tailwind classes

## 🌐 Deployment Options

### Static Hosting (Recommended)
- **Vercel**: Drag and drop the folder
- **Netlify**: Connect GitHub repo or drag and drop
- **GitHub Pages**: Push to repository and enable Pages
- **Surge.sh**: `npx surge renato-portfolio/`

### Traditional Hosting
- Upload files via FTP to any web hosting provider
- Ensure `index.html` is in the root directory
